# 剩余 UNKNOWN 的链路分析与复核任务

用户已授权继续补齐 Guard 失败阻断、身份隔离与 RAG 文档权限，保持规则泛化、真实 JDK 7/8 兼容，复验三个项目后推送。

## 判断与取舍

当前 UNKNOWN 同时包含分析限制与真实语义信息缺失。不能用降低候选绑定要求或把所有资源声明受限的办法减少数量。本轮采用有界扩展，保留逐函数分析，暂不引入完整跨过程、对象堆或异步执行模型。

1. Java 的完整赋值/返回条件表达式降为择一执行的分支；保留隐式虚调用的候选符号，不授予确定绑定。
2. Python 简单变量循环保留迭代来源与元素关系。零次/一次迭代摘要只定位流式候选；不继承集合的 Guard 证明，不证明所有迭代安全。
3. 外部 v2 sink 合同允许一个显式常量参数条件，用于事件/消息封装。条件未知保留 UNKNOWN，不能按未知值跳过；输出构造不等同网络发送。
4. 银行规则保留有界的逐位置结果及原因。区分身份槽缺失、身份信任未证实、资源范围未分类、候选控制、失败放行与分析缺口。规则汇总仍以确定违规优先。
5. 从原因和位置生成复核动作：补映射、扩分析、确认业务/部署语义、运行时负测及证据排查。技术缺口不一律转交人工；人工项要求明确交付证据。
