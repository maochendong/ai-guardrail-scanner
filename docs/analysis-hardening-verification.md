## 性能观察

同一合成类型中，每个方法调用一个固定方法；只统计调用图阶段的 `Cancel.check()` 工作次数，语法解析不计入。两个制品均由真实 JDK 7 执行：

| 方法数 | 修改前 | 修改后 |
| ---: | ---: | ---: |
| 500 | 251,499 | 2,998 |
| 1,000 | 1,002,999 | 5,998 |
| 2,000 | 4,005,999 | 11,998 |
| 4,000 | 16,011,999 | 23,998 |

该样例从近似二次增长降为线性增长。真实项目 JDK 7 单次扫描观测为 CodeBuddy 8.451→4.987 秒、wm-sales-atlas-analysis 13.968→9.635 秒、蒸馏小可乐 6.362→4.241 秒；两轮宿主负载可能不同，这些数值不作为稳定性能基准或加速比例承诺。验收进程均使用 `-Xmx768m`，未进行独立峰值内存测量。

## 保留边界与本地证据

- 静态审计仍不证明外部合同实现正确，不替代真实应用的异常、拒绝、超时、权限或流式运行验证。
- 跨构造器、跨对象与延迟执行关系不能从初始化内控制证明推断；不支持的调用保留 UNKNOWN。
- 正式发布阶段磁盘 I/O 失败仍可能留下部分文件；消费者必须检查任务完成状态，不能仅通过文件存在判断成功。
- 语法缓存仅在单次扫描中存活；没有跨扫描缓存或全局预算共享。
- 本地完整证据位于 `scan-results/hardening-20261015/`：`release/release-verification.json`、`release/matrix/`、`codex/`、`graph-work-comparison.json`、`final-verification.json`。该目录、私有 API 映射及目标报告均不提交公开仓库。
